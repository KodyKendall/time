# TIME — score plan (smooth jazz, sampled instruments)

96 BPM, 4/4 → beat 0.625 s, bar 2.5 s, 58 bars = 145 s. The score is written against the picture:
every section change, hit and swell lands on an on-screen event (cue lists from each segment).
The piece loops: bar 58 decays into the same "singularity" tone that opens bar 0.

Palette: alto + tenor + soprano sax (lead), trumpet / flugelhorn / harmon-muted trumpet,
trombone, horn-section stabs (tp+as+ts+tb), Rhodes, grand piano, vibraphone, upright + fretless
bass, jazz kit (sticks) and brush kit, congas / bongos / shaker / cabasa / claves / woodblock /
triangle / timbales, nylon guitar, clavinet, string pad. SFX layer designed per cue.

Main theme ("Time"): a rising 4th call (C–F) answered by a falling line — heard first on vibes
at the atom (bar 3), in full on soprano sax as the nebula forms (bars 7–8), grooving on alto in
Earth (bars 13–16), muted trumpet (aftermath), flugelhorn (dawn), full section (neural net climax,
+1 key), and alone on Rhodes as the code writes itself; it resolves into the singularity tone.
