# TIME — shot list (transform / flow edition)

96 BPM, 4/4 → 1 bar = 2.5 s. Film ≈ 145 s (58 bars), 30 fps, 3840×2160.
Rule: **no cross-fades, wipes or dissolves.** Every hand-off is a physical transformation,
a continuous camera move, or a match of a shared element (the hand-off frame is dominated
by the shared element so both sequences agree).
